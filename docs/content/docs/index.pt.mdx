O Graphite compila topologia de grafos, matrizes vetoriais quantizadas e estruturas lexicais em um único arquivo binário mapeado em memória (`.graphite`) com zero-copy, fornecendo recuperação e síntese de prompts com latência sub-microssegundo.

## Especificações Técnicas

<Cards>
  <Card title="Formato de Armazenamento em Arquivo Único" href="/docs/engine-internals/binary-format-and-mmap">
    Registros binários contíguos, matrizes de adjacência em Compressed Sparse Row (CSR), matrizes vetoriais quantizadas e pool de interning de strings com verificação de integridade CRC32.
  </Card>
  <Card title="Mapeamento de Memória Zero-Copy" href="/docs/engine-internals/binary-format-and-mmap">
    Mapeamento direto de páginas na memória virtual via `memmap2`, viabilizando latências de recuperação na escala de microssegundos e mais de 500.000 consultas por segundo por thread sem alocação em heap.
  </Card>
  <Card title="Busca Híbrida & Reciprocal Rank Fusion" href="/docs/engine-internals/hybrid-search-and-rrf">
    Funde projeções de cosseno vetorial denso com pontuação lexical invertida BM25 através de Reciprocal Rank Fusion (RRF), eliminando pontos cegos semânticos e siglas de domínio.
  </Card>
  <Card title="Motor de Travessia em Grafo CSR" href="/docs/engine-internals/graph-csr-and-traversal">
    BFS relacional multi-hop sobre topologia Compressed Sparse Row utilizando bitmaps de palavras de 64 bits (`DenseNodeBitSet`), executando verificações de estado bit a bit em um único ciclo de clock.
  </Card>
  <Card title="Poda de Contexto por Orçamento de Tokens" href="/docs/engine-internals/mmr-and-token-pruning">
    Garante que os subgrafos extraídos respeitem estritamente as restrições de tokens do LLM alvo através de Maximal Marginal Relevance (MMR) com métricas de diversidade de Jaccard zero-alocação.
  </Card>
  <Card title="Reranking com Cross-Encoder Integrado" href="/docs/engine-internals/cross-encoder-reranking">
    Inferência local de atenção cruzada via transformer (`bge-reranker-base`) com normalização de logits por Sigmoid e limiar de confiança adaptativo para descarte de candidatos de baixa probabilidade.
  </Card>
</Cards>

## Comparação Arquitetural

| Métrica | Bancos Vetoriais Distribuídos | Bancos de Grafos de Propriedades | Motor Graphite |
| :--- | :--- | :--- | :--- |
| **Arquitetura** | Cliente-Servidor / Nuvem | JVM / Daemon multi-arquivo | **Biblioteca Rust Embarcada / Binário Único** |
| **Meio de Armazenamento** | Shards distribuídos / WAL | B-Tree / Encadeamento de Ponteiros | **Arquivo Binário Mmap Contíguo (`.graphite`)** |
| **Modo de Recuperação** | Busca Aproximada de Vizinhos (ANN) | Travessia de Caminhos em Grafo (Cypher) | **Híbrido: Vetor SIMD + BM25 + Grafo BFS** |
| **Orçamento de Tokens** | Top-K Fixo (sem noção de tokens) | Poda manual de grafo | **Poda Exata por Orçamento de Tokens (MMR)** |
| **Reranking** | Serviço / API externa em Python | Não suportado | **Transformer Cross-Encoder SIMD Local** |
| **Latência de Leitura** | 10ms – 50ms (Sobrecarga de rede) | 15ms – 80ms | **1.6µs – 4.0ms (Em Memória / Mmap)** |
