O Graphite alcança alto rendimento no cálculo de distâncias vetoriais combinando o desenrolamento de laços em 8 vias (para vetorização AVX2/NEON) com um esquema de Quantização Escalar Int8 Assimétrica (SQ8). Essa arquitetura proporciona uma redução de 3.92x na pegada de memória dos vetores, preservando uma correlação de similaridade por cosseno superior a 0.999 em relação a matrizes de ponto flutuante de 32 bits não quantizadas.

---

## 1. Arquitetura de Vetorização SIMD

A busca vetorial em bancos embarcados é limitada principalmente pela largura de banda da memória e pela latência da ALU da CPU. Avaliar milhões de similaridades por cosseno sequencialmente em hardware escalar causa paradas de execução (*pipeline stalls*) geradas por dependências de instruções encadeadas.

```rust
// crates/graphite-core/src/vector/simd.rs
pub fn simd_dot_product(a: &[f32], b: &[f32]) -> Result<f32> {
    if a.len() != b.len() {
        return Err(GraphiteError::VectorDimensionMismatch {
            expected: a.len(),
            found: b.len(),
        });
    }

    let chunks_a = a.chunks_exact(8);
    let chunks_b = b.chunks_exact(8);
    let remainder_a = chunks_a.remainder();
    let remainder_b = chunks_b.remainder();

    let mut sum0 = 0.0f32;
    let mut sum1 = 0.0f32;
    let mut sum2 = 0.0f32;
    let mut sum3 = 0.0f32;

    for (ca, cb) in chunks_a.zip(chunks_b) {
        sum0 += ca[0] * cb[0] + ca[1] * cb[1];
        sum1 += ca[2] * cb[2] + ca[3] * cb[3];
        sum2 += ca[4] * cb[4] + ca[5] * cb[5];
        sum3 += ca[6] * cb[6] + ca[7] * cb[7];
    }

    let mut total = (sum0 + sum1) + (sum2 + sum3);
    for (x, y) in remainder_a.iter().zip(remainder_b.iter()) {
        total += x * y;
    }

    Ok(total)
}
```

### Paralelismo no Nível de Instrução & Quebra de Dependências

Em laços acumuladores ingênuos (`sum += a[i] * b[i]`), cada soma precisa aguardar a instrução anterior gravar seu resultado no registrador acumulador. Em microarquiteturas modernas x86_64 (como Zen 4 ou Golden Cove), as instruções de multiplicação e soma combinadas em ponto flutuante (*fused multiply-add*, `vfmadd231ps`) possuem uma latência de execução de 4 ciclos com vazão de 2 operações por ciclo.

Ao particionar a acumulação em 4 variáveis independentes (`sum0`, `sum1`, `sum2`, `sum3`), o *pipeline* da CPU despacha múltiplas operações de multiplicação-acumulação concorrentemente por portas de execução separadas, evitando bolhas de ociosidade e saturando as ALUs do hardware.

### Orçamento de Registradores YMM & Prevenção de Stack Spilling

A arquitetura x86_64 disponibiliza 16 registradores vetoriais de 256 bits (`%ymm0` a `%ymm15`). Um kernel vetorial otimizado precisa balancear a largura dos acumuladores contra a pressão de registradores físicos:

| Alocação de Registrador | Quantidade YMM | Finalidade |
| :--- | :--- | :--- |
| `%ymm0 .. %ymm3` | 4 Registradores | Vias de acumulação (`sum0` a `sum3`) |
| `%ymm4 .. %ymm5` | 2 Registradores | Entradas de blocos vetoriais da fatia de memória A |
| `%ymm6 .. %ymm7` | 2 Registradores | Entradas de blocos vetoriais da fatia de memória B |
| `%ymm8 .. %ymm15` | 8 Registradores | Reservados para variáveis temporárias do compilador e ponteiros |

Ultrapassar 8 acumuladores paralelos forçaria o alocador de registradores do LLVM a despejar dados na pilha da thread (*stack spilling* via instruções relativas ao registrador `rsp`), gerando acessos redundantes à memória cache que degradam a taxa de varredura.

## 2. Quantização Escalar (SQ8 Int8)

Para maximizar a densidade de memória e a permanência no cache da CPU, o Graphite implementa Quantização Escalar simétrica de 8 bits (SQ8).

### Formulação Matemática

Dado um vetor de ponto flutuante de 32 bits `v` com dimensão `D`, calcula-se o valor máximo absoluto de suas coordenadas:

```text
alpha = max(|v_1|, |v_2|, ..., |v_D|)
```

O passo de escala de quantização `S` e seu inverso `S_inv` são definidos por:

```text
S = alpha / 127.0
S_inv = 127.0 / alpha
```

Cada componente em ponto flutuante `v_i` é mapeado em um inteiro com sinal de 8 bits `q_i` em `[-127, 127]`:

```text
q_i = clamp(round(v_i * S_inv), -127, 127)
```

```rust
// crates/graphite-core/src/vector/quantization.rs
pub struct QuantizedVector {
    pub data: Vec<i8>,
    pub scale: f32,
    pub norm: f32, // módulo do vetor
}

impl QuantizedVector {
    pub fn quantize(v: &[f32]) -> Self {
        let original_norm = norm(v); // calcula o módulo do vetor
        let mut max_abs = 0.0f32;
        for &val in v {
            let abs = val.abs();
            if abs > max_abs { max_abs = abs; }
        }

        if max_abs < 1e-12 {
            return Self { data: vec![0; v.len()], scale: 0.0, norm: 0.0 };
        }

        let inv_scale = 127.0 / max_abs;
        let mut data = Vec::with_capacity(v.len());
        for &val in v {
            let q = (val * inv_scale).round().clamp(-127.0, 127.0) as i8;
            data.push(q);
        }

        Self {
            data,
            scale: max_abs / 127.0,
            norm: original_norm,
        }
    }
}
```

## 3. Execução Assimétrica de Consultas

Em cenários reais de recuperação, os vetores de consulta são gerados dinamicamente em precisão total `f32`, enquanto os documentos armazenados permanecem comprimidos em `i8`. O Graphite executa **Produto Escalar Assimétrico** e **Similaridade por Cosseno Assimétrica** sem desserializar o vetor completo do documento para o heap.

### Formulação Matemática

O produto escalar assimétrico entre a consulta `u` (Float32) e o documento quantizado `q_v` (Int8) com escala `S_v` é calculado diretamente por:

```text
produto_escalar(u, v) ≈ S_v * soma(q_v[i] * u_f[i])  para i em 1..D
```

Para a similaridade por cosseno:

```text
cosseno(u, v) = produto_escalar(u, v) / (modulo(u) * modulo(v))
              ≈ (S_v * soma(q_v[i] * u_f[i])) / (modulo(u) * norm_v)
```

Como o **módulo do vetor** do documento (`norm_v = ||v||_2`) já foi pré-calculado e gravado no bloco durante a ingestão, a varredura executa **zero instruções de raiz quadrada (`sqrt`)** por candidato avaliado.

```rust
// Cálculo da similaridade por cosseno assimétrica
pub fn cosine_similarity_asymmetric(
    &self,
    query_f32: &[f32],
    query_norm: Option<f32>,
) -> Result<f32> {
    if self.data.len() != query_f32.len() {
        return Err(GraphiteError::VectorDimensionMismatch {
            expected: self.data.len(),
            found: query_f32.len(),
        });
    }

    if self.scale == 0.0 || self.norm == 0.0 {
        return Ok(0.0);
    }

    let q_norm = query_norm.unwrap_or_else(|| norm(query_f32)); // módulo da consulta
    if q_norm == 0.0 {
        return Ok(0.0);
    }

    let dot = self.dot_product_asymmetric(query_f32)?;
    let similarity = dot / (q_norm * self.norm);
    Ok(similarity.clamp(-1.0, 1.0))
}
```

## 4. Layout de Memória Zero-Copy dos Vetores

Os registros vetoriais são gravados de forma contígua no arquivo binário. O struct `ZeroCopyVectorBlock` mapeia o bloco na memória virtual e resolve referências via aritmética direta de ponteiros.

### Tabela de Layout Binário por Vetor Quantizado

| Faixa de Bytes | Nome do Campo | Tipo de Dado | Descrição |
| :--- | :--- | :--- | :--- |
| `0x00 .. 0x04` | `scale` | `f32` (4 bytes) | Fator de escala de desquantização `S` |
| `0x04 .. 0x08` | `norm` | `f32` (4 bytes) | Módulo do vetor pré-calculado em Float32 (`norm`) |
| `0x08 .. 0x08+D`| `data` | `[i8; D]` (`D` bytes) | Coordenadas inteiras de 8 bits quantizadas |

Para um modelo de embedding de 384 dimensões (`all-MiniLM-L6-v2`):
* **Padrão Float32 (Sem Quantização):** 384 × 4 = 1.536 bytes por vetor.
* **Quantizado SQ8:** 4 + 4 + 384 = 392 bytes por vetor.
* **Taxa de Compressão de Memória:** **3.92x**.

```rust
// crates/graphite-core/src/storage/vector_block.rs
impl<'a> ZeroCopyVectorBlock<'a> {
    #[inline]
    pub fn get_vector(&self, index: usize) -> Option<(&'a [i8], f32, f32)> {
        if index >= self.count {
            return None;
        }

        let offset = index * self.vector_stride;
        let slice = &self.data_slice[offset..offset + self.vector_stride];

        let scale = f32::from_le_bytes(slice[0..4].try_into().unwrap());
        let norm = f32::from_le_bytes(slice[4..8].try_into().unwrap()); // módulo do vetor
        let data: &'a [i8] = unsafe {
            std::slice::from_raw_parts(
                slice[8..8 + self.dim].as_ptr() as *const i8,
                self.dim,
            )
        };

        Some((data, scale, norm))
    }
}
```

## 5. Fallback & Suporte Multiplataforma

O Graphite adapta-se automaticamente às instruções suportadas pelo processador em tempo de execução:

1. **x86_64 (AVX2 + FMA):** Compila para instruções de 256 bits com multiplicação e soma fundidas (`vfmadd231ps`).
2. **AArch64 / ARM64 (NEON):** Compila para instruções vetoriais de 128 bits (`fmla`).
3. **Fallback Genérico:** Caso extensões vetoriais não estejam disponíveis, a acumulação escalar desenrolada em 8 vias mantém alta eficiência no *pipeline* sem custos de saltos condicionais.
