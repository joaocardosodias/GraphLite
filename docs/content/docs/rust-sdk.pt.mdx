O crate `graphite` expõe uma API fortemente tipada e segura para concorrência multi-thread. Ele permite que aplicações Rust, microsserviços e frameworks de agentes de IA incorporem Grafos de Conhecimento e busca vetorial SIMD diretamente no seu espaço de endereçamento, com zero dependências C/C++ ou servidores externos.

---

## 1. Configuração de Dependências no Cargo

Adicione o `graphite` ao seu arquivo `Cargo.toml`:

```toml
[dependencies]
graphite-db = { version = "0.1", features = ["fastembed", "tiktoken", "serde"] }
```

### Feature Flags Disponíveis

| Feature Flag | Padrão | Descrição |
| :--- | :--- | :--- |
| `fastembed` | Opcional | Ativa a geração de embeddings e reranking com Cross-Encoder via ONNX Runtime local |
| `tiktoken` | Ativado | Ativa a contagem exata de tokens BPE (`cl100k_base` e `o200k_base`) |
| `serde` | Ativado | Permite serialização e desserialização JSON de entidades, grafos e configurações |

## 2. Inicialização & Configuração do Motor

A estrutura `GraphiteConfig` utiliza o padrão Builder para configurar dimensões vetoriais, métricas de distância, quantização e políticas de travessia.

```rust
use graphite::engine::{GraphiteConfig, GraphiteEngine};
use graphite::vector::{Metric, Quantization};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    // 1. Configurar parâmetros do motor
    let config = GraphiteConfig::new()
        .with_dim(384)
        .with_metric(Metric::Cosine)
        .with_quantization(Quantization::ScalarInt8)
        .with_max_tokens(1500)
        .with_mmr_lambda(0.75);

    // 2. Abrir ou criar banco persistente em arquivo único
    let db = GraphiteEngine::open_or_create("knowledge.graphite", config)?;

    println!("Graphite inicializado com sucesso. Total de nós: {}", db.node_count());
    Ok(())
}
```

## 3. Ingestão de Entidades & Relacionamentos

### Inserção Manual de Nós & Criação de Arestas

```rust
// 1. Inserir nós de entidade com vetores de embedding
let v_titan = vec![0.05f32; 384];
let v_ana = vec![0.048f32; 384];

let id_titan = db.upsert_node(
    "Projeto Titan",
    "Projeto",
    "Infraestrutura central de IA generativa com recuperação em sub-milissegundos",
    Some(&v_titan),
)?;

let id_ana = db.upsert_node(
    "Ana Silva",
    "Pessoa",
    "Arquiteta Principal de IA e Líder Técnica do Projeto Titan",
    Some(&v_ana),
)?;

// 2. Conectar as entidades com uma aresta relacional direcionada e ponderada
db.add_edge(id_ana, id_titan, "LIDERA", 0.95, true)?;

// 3. Persistir as mutações atomicamente no arquivo .graphite
db.flush()?;
```

## 4. Recuperação de Contexto GraphRAG

Recupere o contexto sintetizado em Markdown com orçamento estrito de tokens para injeção em prompts de LLMs.

```rust
use graphite::engine::QueryOptions;

fn recuperar_contexto_rag(
    db: &GraphiteEngine,
    vetor_consulta: &[f32],
) -> Result<String, Box<dyn std::error::Error>> {
    // Customizar opções de recuperação
    let opcoes = QueryOptions::default()
        .with_top_k(5)              // 5 nós semente da busca vetorial/BM25
        .with_max_tokens(800)       // Orçamento estrito de 800 tokens
        .with_max_depth(2)          // Travessia BFS de até 2 saltos no grafo
        .with_alpha(0.6);           // 60% peso vetorial / 40% peso estrutural do grafo

    // Executar a busca híbrida
    let resultado = db.retrieve_context(vetor_consulta, Some(opcoes))?;

    println!("Recuperados {} tokens em {} entidades", resultado.token_count, resultado.entities.len());
    
    // Markdown formatado pronto para o prompt de sistema do LLM
    Ok(resultado.markdown)
}
```

## 5. Concorrência Multi-Thread & Segurança de Tipos

O `GraphiteEngine` foi concebido para ambientes de alta concorrência:

* **`Send + Sync`:** Seguro para compartilhamento entre threads, clonável via `Arc`.
* **Concorrência Leitor/Escritor:** Gerenciada internamente por `parking_lot::RwLock`. Múltiplas threads leitoras podem executar varreduras SIMD e travessias BFS simultaneamente sem contenção de travas.

```rust
use std::sync::Arc;
use std::thread;

let db = Arc::new(GraphiteEngine::open_or_create("shared.graphite", config)?);

let mut handles = vec![];
for i in 0..8 {
    let db_clone = Arc::clone(&db);
    handles.push(thread::spawn(move || {
        let dummy_query = vec![0.01f32 * (i as f32); 384];
        let _ = db_clone.retrieve_context(&dummy_query, None);
    }));
}

for handle in handles {
    handle.join().unwrap();
}
```
