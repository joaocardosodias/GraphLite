O Graphite inclui um servidor HTTP embarcado de zero dependências (`graphite serve`) com API REST JSON e suporte a CORS (*Cross-Origin Resource Sharing*). Ele permite que aplicações em Python, TypeScript, Go e interfaces web interajam com bancos `.graphite` sem necessidade de compilar binários nativos em Rust.

---

## 1. Iniciando o Servidor

Inicie o servidor local com `graphite serve`:

```bash
graphite serve -d knowledge.graphite --port 8080 --host 0.0.0.0
```

| Opção | Padrão | Descrição |
| :--- | :--- | :--- |
| `-d, --db <CAMINHO>` | `graphite.graphite` | Caminho do arquivo de banco de dados `.graphite` |
| `-p, --port <PORTA>` | `8080` | Porta TCP do servidor HTTP |
| `-H, --host <HOST>` | `127.0.0.1` | Interface de rede para vinculação (*bind*) |

### `POST /v1/query`

Executa a recuperação GraphRAG híbrida (Vetor SIMD + BM25 + RRF + BFS em CSR + Orçamento MMR) e retorna o contexto em Markdown.

**Corpo da Requisição:**
```json
{
  "query": "Como funciona a gestão de negócios no código civil?",
  "max_tokens": 400,
  "top_k_seeds": 3,
  "type_filter": ["Article", "Law"]
}
```

<Tabs items={['cURL', 'Python', 'TypeScript / Fetch']}>
<Tab value="cURL">

```bash
curl -X POST http://localhost:8080/v1/query \
  -H "Content-Type: application/json" \
  -d '{
    "query": "Como funciona a gestão de negócios no código civil?",
    "max_tokens": 400,
    "top_k_seeds": 3
  }'
```

</Tab>
<Tab value="Python">

```python
import requests

payload = {
    "query": "Como funciona a gestão de negócios no código civil?",
    "max_tokens": 400,
    "top_k_seeds": 3
}

response = requests.post("http://localhost:8080/v1/query", json=payload)
data = response.json()

print(f"Latência: {data['latency_ms']} ms")
print(f"Tokens Recuperados: {data['token_count']}")
print(data['context'])
```

</Tab>
<Tab value="TypeScript / Fetch">

```typescript
const response = await fetch("http://localhost:8080/v1/query", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    query: "Como funciona a gestão de negócios no código civil?",
    max_tokens: 400,
    top_k_seeds: 3,
  }),
});

const data = await response.json();
console.log(`Latência: ${data.latency_ms} ms`);
console.log(data.context);
```

</Tab>
</Tabs>

**Resposta (200 OK):**
```json
{
  "query": "Como funciona a gestão de negócios no código civil?",
  "token_count": 184,
  "context": "# Retrieved Knowledge Context:\n- [codigo_civil: Art. 861] (Tipo: Article, Relevância: 0.92)\n  Descrição: Art. 861. Aquele que, sem autorização do interessado, intervém na gestão de negócio alheio, dirigi-lo-á segundo o interesse e a vontade presumível de seu dono...\n\n# Relacionamentos Estruturais:\n- codigo_civil: Art. 861 --[PARTE_DE]--> Doc: codigo_civil.md",
  "format": "markdown",
  "latency_ms": 2.45
}
```

### `POST /v1/remember`

Registra uma entidade, preferência de usuário ou regra técnica no grafo com desduplicação semântica automática.

**Corpo da Requisição:**
```json
{
  "text": "O usuário prefere respostas concisas e código com tipagem estrita em Rust.",
  "category": "PreferenciaUsuario"
}
```

<Tabs items={['cURL', 'Python', 'TypeScript / Fetch']}>
<Tab value="cURL">

```bash
curl -X POST http://localhost:8080/v1/remember \
  -H "Content-Type: application/json" \
  -d '{
    "text": "O usuário prefere respostas concisas e código com tipagem estrita em Rust.",
    "category": "PreferenciaUsuario"
  }'
```

</Tab>
<Tab value="Python">

```python
import requests

res = requests.post(
    "http://localhost:8080/v1/remember",
    json={
        "text": "O usuário prefere respostas concisas e código com tipagem estrita em Rust.",
        "category": "PreferenciaUsuario"
    }
)
print(res.json())
```

</Tab>
<Tab value="TypeScript / Fetch">

```typescript
const res = await fetch("http://localhost:8080/v1/remember", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    text: "O usuário prefere respostas concisas e código com tipagem estrita em Rust.",
    category: "PreferenciaUsuario",
  }),
});
console.log(await res.json());
```

</Tab>
</Tabs>
