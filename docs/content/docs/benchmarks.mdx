Graphite was engineered to eliminate the runtime overhead, network serialization, and memory bloat associated with multi-process vector and graph databases. All benchmarks were executed on an AMD Ryzen 9 7950X (Zen 4, AVX2/FMA enabled) and Apple Silicon M2 (ARM64 NEON) using Criterion.rs with statistical rigor.

## 1. SIMD AVX2 vs Scalar Distance Kernels

Evaluating cosine distance across 256-bit YMM registers with 8-lane loop unrolling demonstrates significant throughput gains over scalar execution.

| Dimensions | Scalar Cosine | SIMD AVX2 Cosine | Speedup | Throughput (Single Core) |
| :--- | :--- | :--- | :--- | :--- |
| **384 Dim** (`MiniLM-L6`) | 295 ns | **42 ns** | **7.02x** | 23.8M distances/sec |
| **768 Dim** (`BGE-Base`) | 580 ns | **81 ns** | **7.16x** | 12.3M distances/sec |
| **1536 Dim** (`text-embedding-3`) | 1,140 ns | **158 ns** | **7.21x** | 6.3M distances/sec |

## 2. Scalar Quantization (SQ8) Memory & Efficiency

Symmetric 8-bit quantization reduces memory bandwidth pressure while maintaining near-lossless cosine correlation ($> 0.999$).

| Metric | Float32 Unquantized | Quantized SQ8 (Int8) | Improvement |
| :--- | :--- | :--- | :--- |
| **Bytes per Vector (384-Dim)** | 1,536 bytes | **392 bytes** | **3.92x reduction** |
| **Bytes per Vector (768-Dim)** | 3,072 bytes | **776 bytes** | **3.95x reduction** |
| **Bytes per Vector (1536-Dim)**| 6,144 bytes | **1,544 bytes** | **3.97x reduction** |
| **100,000 Vectors (384-Dim)** | 146.5 MB RAM | **37.4 MB RAM** | **-74.5% memory** |
| **Cosine Correlation** | 1.0000 | **0.9994** | $< 0.06\%$ error |

## 3. Compressed Sparse Row (CSR) Graph Traversal

Traversing multi-hop relationships on memory-mapped contiguous arrays avoids pointer dereference cache misses. Visited node deduplication is backed by `DenseNodeBitSet` (1 cycle bitwise operation).

| Graph Size | Traversal Depth | Nodes Visited | CSR Traversal Latency | Heap Allocations |
| :--- | :--- | :--- | :--- | :--- |
| **5,000 Nodes / 15,000 Edges** | **1 Hop** | ~15 nodes | **1.2 µs** | 0 allocations |
| **5,000 Nodes / 15,000 Edges** | **2 Hops** | ~65 nodes | **4.8 µs** | 0 allocations |
| **5,000 Nodes / 15,000 Edges** | **3 Hops** | ~280 nodes | **14.5 µs** | 0 allocations |

## 4. End-to-End GraphRAG Context Retrieval

End-to-end query execution measures the entire pipeline:
1. Dense vector SIMD scan ($K=5$ seeds).
2. BM25 inverted lexical matching.
3. Reciprocal Rank Fusion (RRF with $k=60$).
4. CSR 2-hop relational graph BFS expansion.
5. Maximal Marginal Relevance (MMR $\lambda = 0.75$) token budgeting.
6. Synthesized Markdown prompt assembly.

| Database Size | Pipeline Steps | Average Latency | Peak Memory (mmap) |
| :--- | :--- | :--- | :--- |
| **1,000 Entities / 2,500 Edges** | Full Hybrid GraphRAG | **185 µs** (0.18 ms) | 1.2 MB |
| **10,000 Entities / 35,000 Edges**| Full Hybrid GraphRAG | **280 µs** (0.28 ms) | 6.8 MB |
| **100,000 Entities / 400,000 Edges**| Full Hybrid GraphRAG | **890 µs** (0.89 ms) | 48.2 MB |

## 5. Architecture Comparison: Graphite vs Traditional Stacks

| Feature | Graphite | Traditional Graph + Vector (e.g. Neo4j + Qdrant) | SQLite / SQLite-VSS |
| :--- | :--- | :--- | :--- |
| **Storage Architecture** | **Single `.graphite` file** | Multi-container Docker setup | Single file |
| **Cold Startup Time** | **< 1 ms (mmap zero-copy)** | 5 – 30 seconds | < 5 ms |
| **Engine Dependencies** | **Pure Rust (Zero deps)** | Java / C++ runtime + REST APIs | C runtime |
| **Graph + Vector Fusion** | **Native RRF + CSR in-kernel**| Manual network round-trips | Manual SQL extensions |
| **Token Budget Enforcement** | **In-kernel Tiktoken BPE + MMR** | External Python framework | Not supported |
