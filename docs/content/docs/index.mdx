Graphite compiles graph topology, quantized vector matrices, and lexical structures into a zero-copy memory-mapped (`.graphite`) binary file, providing sub-microsecond retrieval and prompt synthesis.

## Technical Specifications

<Cards>
  <Card title="Single-File Storage Format" href="/docs/engine-internals/binary-format-and-mmap">
    Contiguous binary records, Compressed Sparse Row (CSR) edge matrices, scalar-quantized vector arrays, and string interning pools with CRC32 polynomial integrity verification.
  </Card>
  <Card title="Zero-Copy Memory Mapping" href="/docs/engine-internals/binary-format-and-mmap">
    Direct virtual memory page mapping via `memmap2`, enabling sub-microsecond retrieval latencies and over 500,000 queries per second per thread without heap allocation overhead.
  </Card>
  <Card title="Hybrid Search & Reciprocal Rank Fusion" href="/docs/engine-internals/hybrid-search-and-rrf">
    Fuses dense vector cosine projections with BM25 inverted lexical scoring using Reciprocal Rank Fusion (RRF) to eliminate semantic and domain-specific acronym blind spots.
  </Card>
  <Card title="CSR Graph Traversal Engine" href="/docs/engine-internals/graph-csr-and-traversal">
    Multi-hop relational BFS over Compressed Sparse Row topology utilizing 64-bit word bitmaps (`DenseNodeBitSet`) that execute bitwise state checks in a single CPU clock cycle.
  </Card>
  <Card title="Token-Budgeted Context Pruning" href="/docs/engine-internals/mmr-and-token-pruning">
    Ensures extracted subgraphs strictly adhere to target LLM token constraints (Token Budget) using Maximal Marginal Relevance (MMR) with zero-allocation two-pointer Jaccard diversity metrics.
  </Card>
  <Card title="Embedded Cross-Encoder Reranking" href="/docs/engine-internals/cross-encoder-reranking">
    Local transformer cross-attention inference (`bge-reranker-base`) with Sigmoid logit normalization and adaptive confidence thresholding to discard low-probability candidates.
  </Card>
</Cards>

## Architectural Comparison

| Metric | Distributed Vector Databases | Property Graph Databases | Graphite Engine |
| :--- | :--- | :--- | :--- |
| **Architecture** | Client-Server / Cloud Cluster | JVM / Multi-file daemon | **Single Embedded Rust Library / Binary** |
| **Storage Medium** | Distributed shards / WAL | B-Tree / Pointer Chains | **Contiguous Binary Mmap (`.graphite`)** |
| **Retrieval Mode** | Vector Approximate Nearest Neighbor | Graph Path Traversal (Cypher) | **Hybrid Vector + BM25 + Graph BFS** |
| **Token Budgeting** | Fixed Top-K (token-unaware) | Manual graph trimming | **Exact Token Budget Pruning (MMR)** |
| **Reranking** | External Python service / API | Not supported | **Local SIMD Cross-Encoder Transformer** |
| **Read Latency** | 10ms – 50ms (Network overhead) | 15ms – 80ms | **1.6µs – 4.0ms (In-Memory / Mmap)** |

## Interface Reference

<Tabs items={['CLI', 'Rust SDK', 'MCP Server']}>
  <Tab value="CLI">
```bash
# 1. Initialize database with 384 dimensions and Scalar Int8 quantization
graphite init -d knowledge.graphite

# 2. Ingest structured or legal documents with semantic article chunking
graphite ingest ./documents -d knowledge.graphite --no-tmp

# 3. Execute hybrid query with Cross-Encoder reranking
graphite -d knowledge.graphite query -T "quais sao as hipoteses de anulacao do negocio juridico" --rerank -v
```
  </Tab>

  <Tab value="Rust SDK">
```rust
use graphite_core::engine::{GraphiteConfig, GraphiteEngine, QueryOptions};

fn main() -> anyhow::Result<()> {
    let config = GraphiteConfig::new()
        .with_dim(384)
        .with_max_tokens(2048);

    let engine = GraphiteEngine::open_or_create("knowledge.graphite", config)?;

    let query_embedding = vec![0.042f32; 384];
    let query_options = QueryOptions {
        max_tokens: Some(1500),
        expand_hops: 2,
        ..Default::default()
    };

    let result = engine.retrieve_context(&query_embedding, Some(query_options))?;
    println!("Formatted LLM Context ({} tokens):\n{}", result.token_count, result.markdown);

    Ok(())
}
```
  </Tab>
