## 3. Referência de Subcomandos

### `graphite init`

Inicializa um novo banco de dados binário `.graphite` vazio em arquivo único.

```bash
graphite init -d knowledge.graphite --dim 384 --metric cosine --quantization scalar-int8 -t 2048
```

| Opção | Abreviação | Padrão | Descrição |
| :--- | :--- | :--- | :--- |
| `--dim <NUM>` | `-D` | `384` | Dimensão dos embeddings vetoriais densos |
| `--metric <METRICA>` | `-m` | `cosine` | Métrica de distância: `cosine`, `dot-product`, `l2` |
| `--quantization <MODO>`| `-q` | `scalar-int8` | Modo de compressão: `scalar-int8` (SQ8), `none` |
| `--max-tokens <NUM>` | `-t` | `2048` | Limite padrão de orçamento de tokens para prompts |
| `--force` | `-f` | `false` | Sobrescreve o arquivo se ele já existir |

---

### `graphite ingest`

Analisa recursivamente diretórios com documentos (Markdown, PDF, Texto, JSON, CSV), aplica segmentação semântica hierárquica (*chunking*), computa embeddings densos, constrói o índice invertido BM25 e grava o arquivo `.graphite` final.

```bash
graphite ingest ./documentos -d knowledge.graphite --chunk-size 350 --chunk-overlap 40 --no-tmp
```

| Opção | Abreviação | Padrão | Descrição |
| :--- | :--- | :--- | :--- |
| `<CAMINHO>` | *(Posicional)* | `.` | Diretório ou arquivo com documentos para ingestão |
| `--chunk-size <TOKENS>`| `-s` | `350` | Capacidade alvo de tokens por trecho de texto |
| `--chunk-overlap <TOKENS>`| `-o` | `40` | Tokens de sobreposição entre janelas deslizantes |
| `--extensions <LISTA>` | `-e` | Todas suportadas | Extensões aceitas separadas por vírgula (ex: `md,txt,pdf`) |
| `--max-files <NUM>` | — | `1000` | Quantidade máxima de arquivos a processar |
| `--watch` | `-w` | `false` | Modo contínuo: re-indexa automaticamente ao alterar arquivos |
| `--force` | `-f` | `false` | Força a re-indexação ignorando hashes de conteúdo salvos |
| `--no-tmp` | — | `false` | Gravação direta sem arquivos temporários de estágio |

---

### `graphite query`

Executa a recuperação GraphRAG híbrida unificando busca vetorial SIMD, correspondência léxica BM25, Reciprocal Rank Fusion (RRF), travessia em grafo CSR e reranking opcional com Cross-Encoder.

```bash
graphite -d knowledge.graphite query -T "artigo 861 do codigo civil" --rerank -v
```

| Opção | Abreviação | Padrão | Descrição |
| :--- | :--- | :--- | :--- |
| `--text <CONSULTA>` | `-T` | — | Consulta textual em linguagem natural (auto-vetorizada em Rust) |
| `--vector <FLOATS>` | `-V` | — | Floats do vetor de consulta separados por vírgula |
| `--seeds <NOMES>` | `-s` | — | Nomes de entidades semente para exploração no grafo |
| `--top-k <NUM>` | `-k` | `5` | Quantidade de nós semente a recuperar |
| `--tokens <NUM>` | `-t` | Padrão config | Sobrescrita do orçamento de tokens do prompt |
| `--depth <SALTOS>` | — | `2` | Profundidade máxima de travessia BFS no grafo |
| `--alpha <FLOAT>` | — | `0.6` | Peso híbrido: `1.0` (100% vetor) a `0.0` (100% grafo) |
| `--type <FILTRO>` | `-y` | — | Filtra entidades por tipo (ex: `Function,Struct,Article`) |
| `--rerank` | — | `false` | Ativa o reranking semântico local via Cross-Encoder |
| `--format <MODO>` | `-f` | `markdown` | Formato de saída: `markdown`, `json`, `triples` |

---

### `graphite remember`

Registra uma memória de agente de IA, preferência de usuário, tarefa ou regra de sistema com geração automática de embedding e vínculo semântico relacional no grafo.

```bash
graphite -d agent.graphite remember "O usuário prefere respostas em português e código com tipos estritos em Rust." -c preference
```

| Opção | Abreviação | Padrão | Descrição |
| :--- | :--- | :--- | :--- |
| `<TEXTO>` | *(Posicional)* | — | Conteúdo textual da memória a registrar |
| `--category <ROTULO>` | `-c` | `AgentMemory` | Categoria: `preference`, `fact`, `task`, `rule` |
| `--link-nearest` | `-l` | `true` | Conecta a memória aos nós mais próximos semanticamente |

---

### `graphite insert-node` & `insert-edge`

Comandos de baixo nível para construção manual de nós e arestas relacionais no grafo.

```bash
# Inserir Entidade
graphite -d knowledge.graphite insert-node \
  --name "GraphiteEngine" \
  --type "Struct" \
  --description "Motor embarcado de alta performance para GraphRAG em Rust" \
  --auto-embed

# Inserir Aresta Relacional
graphite -d knowledge.graphite insert-edge \
  --source "GraphiteEngine" \
  --target "CsrGraph" \
  --relation "USES" \
  --weight 0.95
```

## 4. Tutorial Passo a Passo

<Steps>
<Step>
### 1. Inicializar o Banco de Dados
Crie um banco de dados vazio configurado para embeddings de 384 dimensões:
```bash
graphite init -d knowledge.graphite -D 384
```
</Step>

<Step>
### 2. Ingerir o Acervo de Documentos
Processe uma pasta contendo arquivos Markdown, técnicos ou jurídicos:
```bash
graphite ingest ./documentos -d knowledge.graphite --no-tmp
```
</Step>

<Step>
### 3. Consultar com Reranking Cross-Encoder
Execute uma busca semântica profunda e obtenha o contexto formatado em Markdown:
```bash
graphite -d knowledge.graphite query -T "gestão de negócios de terceiros" --rerank
```
</Step>

<Step>
### 4. Verificar a Integridade do Banco
Inspecione o alinhamento binário da memória e as somas de verificação:
```bash
graphite -d knowledge.graphite inspect
```
</Step>
</Steps>
