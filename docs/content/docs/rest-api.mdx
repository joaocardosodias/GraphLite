Graphite includes an embedded, zero-dependency HTTP server (`graphite serve`) providing a RESTful JSON API with Cross-Origin Resource Sharing (CORS) enabled. It allows Python, TypeScript, Go, and web applications to interact with `.graphite` databases without embedding native Rust binaries.

---

## 1. Starting the Server

Launch the embedded server with `graphite serve`:

```bash
graphite serve -d knowledge.graphite --port 8080 --host 0.0.0.0
```

| Option | Default | Description |
| :--- | :--- | :--- |
| `-d, --db <PATH>` | `graphite.graphite` | Target path to the `.graphite` database file |
| `-p, --port <PORT>` | `8080` | Port number to bind the HTTP server |
| `-H, --host <HOST>` | `127.0.0.1` | Network interface to bind |

### `POST /v1/query`

Executes hybrid GraphRAG retrieval (SIMD Vector + BM25 + RRF + CSR Graph Expansion + MMR Token Budgeting) and returns formatted Markdown context.

**Request Body:**
```json
{
  "query": "Como funciona a gestão de negócios no código civil?",
  "max_tokens": 400,
  "top_k_seeds": 3,
  "type_filter": ["Article", "Law"]
}
```

<Tabs items={['cURL', 'Python', 'TypeScript / Fetch']}>
<Tab value="cURL">

```bash
curl -X POST http://localhost:8080/v1/query \
  -H "Content-Type: application/json" \
  -d '{
    "query": "Como funciona a gestão de negócios no código civil?",
    "max_tokens": 400,
    "top_k_seeds": 3
  }'
```

</Tab>
<Tab value="Python">

```python
import requests

payload = {
    "query": "Como funciona a gestão de negócios no código civil?",
    "max_tokens": 400,
    "top_k_seeds": 3
}

response = requests.post("http://localhost:8080/v1/query", json=payload)
data = response.json()

print(f"Latency: {data['latency_ms']} ms")
print(f"Retrieved Tokens: {data['token_count']}")
print(data['context'])
```

</Tab>
<Tab value="TypeScript / Fetch">

```typescript
const response = await fetch("http://localhost:8080/v1/query", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    query: "Como funciona a gestão de negócios no código civil?",
    max_tokens: 400,
    top_k_seeds: 3,
  }),
});

const data = await response.json();
console.log(`Latency: ${data.latency_ms} ms`);
console.log(data.context);
```

</Tab>
</Tabs>

### `POST /v1/remember`

Records an entity, user preference, or architectural rule into the knowledge graph with real-time semantic deduplication.

**Request Body:**
```json
{
  "text": "User prefers concise answers and strictly typed Rust code examples.",
  "category": "UserPreference"
}
```

<Tabs items={['cURL', 'Python', 'TypeScript / Fetch']}>
<Tab value="cURL">

```bash
curl -X POST http://localhost:8080/v1/remember \
  -H "Content-Type: application/json" \
  -d '{
    "text": "User prefers concise answers and strictly typed Rust code examples.",
    "category": "UserPreference"
  }'
```

</Tab>
<Tab value="Python">

```python
import requests

res = requests.post(
    "http://localhost:8080/v1/remember",
    json={
        "text": "User prefers concise answers and strictly typed Rust code examples.",
        "category": "UserPreference"
    }
)
print(res.json())
```

</Tab>
<Tab value="TypeScript / Fetch">

```typescript
const res = await fetch("http://localhost:8080/v1/remember", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    text: "User prefers concise answers and strictly typed Rust code examples.",
    category: "UserPreference",
  }),
});
console.log(await res.json());
```

</Tabs>

### `POST /v1/ingest`

Triggers an on-demand document ingestion pass over a directory or file.

**Request Body:**
```json
{
  "path": "./documents",
  "chunk_size": 350,
  "chunk_overlap": 40,
  "force": false
}
```
