The official Python package **`graphite-db`** exposes high-performance native PyO3 bindings directly to the Graphite GraphRAG engine. It delivers pure Rust speed (SIMD AVX2, zero-copy virtual memory, and sub-millisecond retrieval) with an ergonomic Python interface.

---

## 1. Installation

Install the pre-compiled binary wheel from PyPI:

```bash
pip install graphite-database
```

---

## 2. Quickstart Example

```python
import graphite_db as graphite

# 1. Open or create an embedded database
db = graphite.open("knowledge.graphite", dim=384, max_tokens=400)

# 2. Insert entities and create connections
id_auth = db.insert("AuthService", entity_type="Module", description="Validates JWTs and sessions")
id_db = db.insert("UsersDB", entity_type="Database", description="PostgreSQL primary cluster")

db.connect("AuthService", "UsersDB", relation="CONNECTS_TO", weight=0.95)
db.flush()

# 3. Query GraphRAG context with automatic FastEmbed local embedding
result = db.query("How does authentication connect to the database?")

print(f"Retrieved tokens: {result.token_count}")
print(result.markdown)
```

## 3. Ephemeral In-Memory Storage

For temporary test sessions, conversation state, or stateless worker tasks, create an in-memory database using Python's context manager:

```python
import graphite_db as graphite

with graphite.in_memory(dim=384) as db:
    # Remember rules or facts with automatic deduplication
    db.remember("User prefers responses in Portuguese.", category="UserPreference")
    db.remember("Production endpoints must return Result types.", category="CodingStandard")

    result = db.query("What language does the user prefer?")
    print(result.markdown)
```

## 4. Custom Vectors & FastEmbed

You can either pass pre-computed embedding vectors (from OpenAI, Cohere, or local PyTorch models) or use the built-in `graphite.embed()` function:

```python
import graphite_db as graphite

# Generate 384-dimensional dense vectors on CPU with zero API costs
vector = graphite.embed("How does authentication work?")

db = graphite.in_memory(dim=384)
result = db.retrieve_context(
    vector=vector,
    query_text="authentication",
    max_tokens=300,
    top_k=5
)

print(result.markdown)
```

## 5. Method Reference

| Method | Parameters | Return Type | Description |
| :--- | :--- | :--- | :--- |
| `graphite.open()` | `path, dim, max_tokens, metric, quantization` | `Graphite` | Opens or creates a `.graphite` file |
| `graphite.in_memory()` | `dim, max_tokens, metric, quantization` | `Graphite` | Creates ephemeral in-memory database |
| `db.query()` | `text, top_k, max_tokens, max_depth, alpha` | `QueryResult` | Hybrid vector + lexical search with local embedding |
| `db.retrieve_context()` | `vector, query_text, top_k, max_tokens` | `QueryResult` | Query with raw floating-point vector |
| `db.insert()` | `name, entity_type, description, vector` | `int` | Inserts entity node and returns node ID |
| `db.remember()` | `text, category` | `int` | Inserts fact with automatic embedding |
| `db.connect()` | `source_name, target_name, relation, weight` | `None` | Connects two entity names with directed edge |
| `db.add_edge()` | `source_id, target_id, relation, weight, directed` | `None` | Connects two numeric node IDs |
| `db.inspect()` | None | `dict` | Returns node counts, edge counts, and dimensions |
| `db.flush()` | None | `None` | Persists all memory mutations to disk |
| `db.close()` | None | `None` | Closes file mappings safely |
