The `graphite-core` crate exposes a strongly-typed, thread-safe embedded database engine. It allows Rust applications, microservices, and AI agent frameworks to embed Knowledge Graphs and SIMD vector retrieval directly into their address space with zero C/C++ dependencies or external database servers.

---

## 1. Cargo Dependency Setup

Add `graphite-core` to your `Cargo.toml`:

```toml
[dependencies]
graphite-core = { version = "0.1", features = ["fastembed", "tiktoken", "serde"] }
```

### Feature Flags

| Feature Flag | Default | Description |
| :--- | :--- | :--- |
| `fastembed` | Optional | Enables in-process ONNX embedding generation and Cross-Encoder reranking |
| `tiktoken` | Enabled | Enables exact BPE token counting with OpenAI `cl100k_base` and `o200k_base` |
| `serde` | Enabled | Enables JSON serialization/deserialization for entities, graphs, and configs |

## 2. Engine Initialization & Configuration

`GraphiteConfig` provides a builder pattern for customizing vector dimensionality, distance metrics, quantization, and traversal policies.

```rust
use graphite_core::engine::{GraphiteConfig, GraphiteEngine};
use graphite_core::vector::{Metric, Quantization};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    // 1. Configure engine parameters
    let config = GraphiteConfig::new()
        .with_dim(384)
        .with_metric(Metric::Cosine)
        .with_quantization(Quantization::ScalarInt8)
        .with_max_tokens(1500)
        .with_mmr_lambda(0.75);

    // 2. Open or create persistent single-file database
    let db = GraphiteEngine::open_or_create("knowledge.graphite", config)?;

    println!("Graphite initialized. Node count: {}", db.node_count());
    Ok(())
}
```

## 3. Ingesting Entities & Relationships

### Manual Entity Insertion & Relational Linking

```rust
// 1. Insert entity nodes with dense embedding vectors
let v_titan = vec![0.05f32; 384];
let v_ana = vec![0.048f32; 384];

let id_titan = db.upsert_node(
    "Project Titan",
    "Project",
    "Generative AI core infrastructure with sub-millisecond retrieval",
    Some(&v_titan),
)?;

let id_ana = db.upsert_node(
    "Ana Silva",
    "Person",
    "Principal AI Architect and Tech Lead for Project Titan",
    Some(&v_ana),
)?;

// 2. Connect entities with a directed, weighted relationship
db.add_edge(id_ana, id_titan, "LEADS", 0.95, true)?;

// 3. Persist mutations atomically to the .graphite disk file
db.flush()?;
```

## 4. GraphRAG Context Retrieval

Retrieve token-budgeted prompt context for LLMs using vector similarity, BM25 indexing, and relational graph expansion.

```rust
use graphite_core::engine::QueryOptions;

fn retrieve_rag_context(
    db: &GraphiteEngine,
    query_vector: &[f32],
) -> Result<String, Box<dyn std::error::Error>> {
    // Customize retrieval options
    let options = QueryOptions::default()
        .with_top_k(5)              // 5 seed nodes from vector/BM25 search
        .with_max_tokens(800)       // Enforce strict 800 token budget
        .with_max_depth(2)          // 2-hop BFS graph expansion
        .with_alpha(0.6);           // 60% vector / 40% graph structural weight

    // Execute hybrid retrieval
    let result = db.retrieve_context(query_vector, Some(options))?;

    println!("Retrieved {} tokens across {} entities", result.token_count, result.entities.len());
    
    // Formatted Markdown ready for system prompt injection
    Ok(result.markdown)
}
```

## 5. Thread Safety & Concurrency

`GraphiteEngine` is designed for high-concurrency environments:

* **`Send + Sync`:** Fully thread-safe, cloneable via `Arc`.
* **Read/Write Concurrency:** Managed internally by `parking_lot::RwLock`. Multiple reader threads can execute SIMD vector scans and BFS traversals concurrently without lock contention.

```rust
use std::sync::Arc;
use std::thread;

let db = Arc::new(GraphiteEngine::open_or_create("shared.graphite", config)?);

let mut handles = vec![];
for i in 0..8 {
    let db_clone = Arc::clone(&db);
    handles.push(thread::spawn(move || {
        let dummy_query = vec![0.01f32 * (i as f32); 384];
        let _ = db_clone.retrieve_context(&dummy_query, None);
    }));
}

for handle in handles {
    handle.join().unwrap();
}
```
