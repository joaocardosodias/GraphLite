O pacote oficial Python **`graphite-db`** expõe bindings nativas em PyO3 diretamente para o motor GraphRAG do Graphite. Ele entrega a velocidade de Rust puro (SIMD AVX2, memória mapeada zero-copy e busca em microssegundos) com a facilidade do Python.

---

## 1. Instalação

Instale o pacote pré-compilado diretamente via PyPI:

```bash
pip install graphite-db
```

---

## 2. Exemplo de Início Rápido

```python
import graphite_db as graphite

# 1. Abre ou cria um banco embutido
db = graphite.open("knowledge.graphite", dim=384, max_tokens=400)

# 2. Insere entidades e cria conexões
id_auth = db.insert("AuthService", entity_type="Module", description="Valida JWTs e sessões")
id_db = db.insert("UsersDB", entity_type="Database", description="Cluster primário PostgreSQL")

db.connect("AuthService", "UsersDB", relation="CONNECTS_TO", weight=0.95)
db.flush()

# 3. Consulta contexto GraphRAG com embedding local automático via FastEmbed
resultado = db.query("Como o serviço de autenticação se conecta ao banco?")

print(f"Tokens recuperados: {resultado.token_count}")
print(resultado.markdown)
```

## 3. Armazenamento Efêmero em Memória

Para sessões temporárias de teste, memória de conversa ou tarefas de agentes, crie um banco em memória usando o gerenciador de contexto do Python:

```python
import graphite_db as graphite

with graphite.in_memory(dim=384) as db:
    # Registra regras ou preferências com desduplicação automática
    db.remember("O usuário prefere respostas curtas em português.", category="PreferenciaUsuario")
    db.remember("Endpoints de produção devem retornar tipos Result estruturados.", category="PadraoCodigo")

    resultado = db.query("Qual o idioma de preferência do usuário?")
    print(resultado.markdown)
```

## 4. Vetores Customizados & FastEmbed

Você pode passar vetores pré-calculados (de OpenAI, Cohere ou PyTorch) ou usar a função integrada `graphite.embed()`:

```python
import graphite_db as graphite

# Gera vetores densos de 384 dimensões na CPU sem custos de API
vetor = graphite.embed("Como funciona a autenticação?")

db = graphite.in_memory(dim=384)
resultado = db.retrieve_context(
    vector=vetor,
    query_text="autenticacao",
    max_tokens=300,
    top_k=5
)

print(resultado.markdown)
```

## 5. Tabela de Métodos

| Método | Parâmetros | Tipo de Retorno | Descrição |
| :--- | :--- | :--- | :--- |
| `graphite.open()` | `path, dim, max_tokens, metric, quantization` | `Graphite` | Abre ou cria um arquivo `.graphite` |
| `graphite.in_memory()` | `dim, max_tokens, metric, quantization` | `Graphite` | Cria um banco efêmero em memória |
| `db.query()` | `text, top_k, max_tokens, max_depth, alpha` | `QueryResult` | Busca híbrida vetor + texto com embedding local |
| `db.retrieve_context()` | `vector, query_text, top_k, max_tokens` | `QueryResult` | Busca com vetor numérico explícito |
| `db.insert()` | `name, entity_type, description, vector` | `int` | Insere nó de entidade e retorna o ID numérico |
| `db.remember()` | `text, category` | `int` | Insere fato com embedding automático |
| `db.connect()` | `source_name, target_name, relation, weight` | `None` | Conecta dois nós por nome com aresta direcionada |
| `db.add_edge()` | `source_id, target_id, relation, weight, directed` | `None` | Conecta dois nós por ID numérico |
| `db.inspect()` | Nenhum | `dict` | Retorna contagem de nós, arestas e dimensões |
| `db.flush()` | Nenhum | `None` | Grava todas as alterações atômicas no disco |
| `db.close()` | Nenhum | `None` | Fecha os mapeamentos de memória com segurança |
