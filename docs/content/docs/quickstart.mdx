<Steps>
<Step>
### Binary Installation

Compile and install the `graphite` CLI binary locally via Cargo:

```bash
cargo install --path crates/graphite-cli --force
```

Confirm binary registration in your system path:

```bash
graphite --version
```
</Step>

<Step>
### Database Initialization

Initialize a new database file configured with 384 vector dimensions, Cosine distance metric, Scalar Int8 quantization, and a 2048 token prompt budget:

```bash
graphite init -d knowledge.graphite
```

Terminal output:
```text
=== Graphite Database Initialized ===
  Database File:        "knowledge.graphite"
  Vector Dimension:     384 dimensions
  Distance Metric:      Cosine
  Quantization:         ScalarInt8
  Default Token Budget: 2048
```
</Step>

<Step>
### Document Ingestion

Populate a directory with Markdown or plain text documents (e.g., `./documents`) and run the ingestion pipeline:

```bash
graphite ingest ./documents -d knowledge.graphite --no-tmp
```

The ingestion process executes:
1. **Semantic Boundary Parsing:** Partitions documents along structural sections without slicing sentences or clauses.
2. **SIMD Batch Embedding:** Computes dense vector representations in 32-node batches via fast local transformers.
3. **Graph Topology Construction:** Generates inter-chunk and hierarchical relational edges.
4. **Atomic Flush:** Commits all nodes, CSR blocks, vector arrays, and string interner tables to disk in a single contiguous write.
</Step>

<Step>
### Semantic Retrieval & Reranking

Execute a query with integrated Cross-Encoder reranking:

```bash
graphite -d knowledge.graphite query -T "o que diz o artigo 861 do codigo civil" --rerank -v
```

Terminal output:
```markdown

  Description:
```

</Step>
</Steps>

<Callout type="info" title="Continuous Ingestion">
To automatically detect and index modified or new documents during active development, supply the `--watch` flag:
```bash
graphite ingest ./documents -d knowledge.graphite --watch
```
</Callout>
